# CheckItOffApp 
Check it out here: https://check-it-off-app.vercel.app/

A full-stack productivity app that provides personalized to-do lists and task history with secure user authentication and clean, responsive design.

## 🔧 Tech Stack  
**Frontend:** React.js, ChakraUI, Figma  
**Backend:** Node.js, Express.js, MongoDB  
**Deployment:** Vercel CI/CD  
**Tools:** Postman, Git

## ✨ Features  
- Secure **user authentication** using RESTful APIs (JWT-based)  
- **Personalized to-do lists** with the ability to create, complete, and delete tasks  
- **Historical tracking** of completed tasks for user insights  
- **CI/CD pipeline** via Vercel for seamless deployment  
- UI/UX design influenced by [Microsoft’s productivity research](https://www.microsoft.com/en-us/worklab) for increased task efficiency
